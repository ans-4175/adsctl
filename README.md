# adsctl

Proposed Go and Cobra CLI for managing advertising across platforms, starting with Meta. Designed primarily for AI agents operating across multiple clients.

The project currently contains design documentation; no executable has been implemented.

- [Architecture and product design](docs/design.md)
- [CLI UX and command reference](docs/cli-reference.md)
- [Meta API research and validation gaps](docs/meta-research.md)
- [Domain glossary](CONTEXT.md)
- [Output contract ADR](docs/adr/0001-agent-output-contract.md)

Implementation sequence: discovery and reporting, monitoring, targeted management, then campaign creation workflows.
